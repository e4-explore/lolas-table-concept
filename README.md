# Lola's Table redesign concept

Unofficial redesign concept for lolastable.com, built as a pitch mockup. Not affiliated with the restaurant and not its live site.

- `index.html` is the whole site (single self-contained file).
- Search indexing is turned off (`noindex` meta tag and `robots.txt`) so the concept doesn't show up in Google.

## Deploy on Vercel
Import this repo in Vercel with the framework preset set to "Other". No build step is needed.
